# TAAMEN 2.0 — V15 Remaster

هذه الحزمة هي نسخة مصدر نظيفة من V15 بعد إصلاح تجربة مكتبة الخطط ومعالجة مشكلة أرشفة ملفات Cloudflare المحلية.

## أهم التعديلات

- عرض خمسة مواضع واضحة للخطط في كل صيغة على حدة: 5v5 و7v7.
- إبقاء مكتبة الخطط مطوية افتراضياً، وإظهار اسم الخطة فقط قبل توسيعها.
- إضافة زر (+) لإضافة التكتيك الحالي إلى المكتبة عند توفر حساب سحابي موثق ومستودع خطط متصل.
- توسيع الخطة المحفوظة يعرض معاينة مصغّرة وأزرار فتح الخطة في المسودة الحالية، وإعادة التسمية، والحذف.
- فتح الخطة يستمر باستخدام تأكيد الاستبدال والحفظ المحلي أولاً قبل تبديل الملعب المعروض.
- الملف المحلي يحتفظ بمسودة العمل فقط؛ لا تُنشأ مكتبة دائمة داخل IndexedDB. هذا يحافظ على قرار الخصوصية السابق.
- إظهار الخانات الخمس حتى عندما لا يكون الحساب السحابي متاحاً، مع توضيح سبب قفل الإضافة.
- تنظيف حزمة ZIP من `.wrangler` و`dist` و`node_modules` ومخرجات التشغيل حتى لا تُضمّن قواعد SQLite المقفلة أو الملفات المولّدة.

## قيد معروف يجب عدم فهمه على أنه مكتمل

نسخة V15 Remaster لا تضيف حسابات أو بريد إلكتروني أو مستودع D1 للمكتبة السحابية. لذلك يعمل زر (+) من ناحية الواجهة مع توضيح سبب عدم الإتاحة للملف المحلي، ويصبح الحفظ الفعلي متاحاً فقط عندما يمرّر التطبيق `cloudAccountReady=true` ومستودعاً موثّقاً يطبّق واجهة `TacticalPlanLibraryRepository`. لا توجد خطط سحابية سابقة يمكن عرضها ما لم يوفّر التطبيق هذا المستودع.

## تركيب المشروع

1. فك ضغط الحزمة إلى مجلد جديد.
2. افتح PowerShell داخل مجلد `TAAMEN_2_0_V15_REMASTER`.
3. نفّذ `npm ci` لتثبيت الاعتماديات تماماً من `package-lock.json`.
4. نفّذ اختبارات QA والاختبارات الثلاثة كما هو موضح أدناه.
5. نفّذ البناء والمعاينة.

```powershell
npm ci
npm run qa:final
npm run test:frontend
npm run test:backend
npm run test:worker
npm run typecheck
npm run build:production
npm run preview
```

## ملاحظة حول `.wrangler`

مجلد `.wrangler` محلي ومولّد بواسطة Cloudflare Vite Plugin، ولا يُوزّع داخل هذه الحزمة. سيُنشئه البناء/المعاينة عند الحاجة. لا تنسخ مجلد `.wrangler` من النسخة القديمة إلى هذه الحزمة، ولا تضغط ملفات SQLite داخله أثناء تشغيل المعاينة.

## الإصدار

`V15 Remaster` تسمية تطويرية داخلية فقط. بقي `package.json` وإصدار التطبيق على `2.0.0`، ولم يحدث أي نشر على Cloudflare أو الموقع الحي.
