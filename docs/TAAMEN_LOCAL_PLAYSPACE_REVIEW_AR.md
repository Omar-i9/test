# TAAMEN 2.0 — دليل مراجعة التعديلات المحلية

هذه نسخة عمل منفصلة مبنية على بنية TAAMEN 2.0 الأصلية (React + TypeScript + Vite). لم يتم تحويل التطبيق إلى صفحة HTML مستقلة، ولم يتم نشر أي تغيير إلى الموقع الحقيقي.

## ما الذي تغيّر؟

### 1. التنقل الرئيسي
- أصبحت الوجهات الأساسية خمسًا: الرئيسية، الملاعب، مساحة اللعب، تحليلاتي، ومساعد تأمين.
- أُزيل تبديل اللغة والوقت من الشريط العلوي.
- أضيف زر الإعدادات بجانب الصورة الشخصية في الشريط العلوي.
- عند الدخول إلى مساحة الحساب تُخفى قائمة التنقل الأساسية، وتظهر وصلة رجوع مناسبة.

### 2. مساحة اللعب
تجمع صفحة واحدة ثلاثة أقسام داخلية:
- **مبارياتي:** استخدام صفحة إدارة المباريات الحالية بدل إعادة بناء منطق إنشاء المباريات.
- **السجل والأرشيف:** الاستمرار باستخدام مصدر بيانات المباريات نفسه، لا إنشاء أرشيف مستقل مكرر.
- **الملعب التكتيكي:** محرر SVG جديد مستوحى من النموذج المرفق، يتضمن تشكيلات 5 ضد 5 و7 ضد 7، تحريك اللاعبين، رسم التمريرات والتحركات والضغط والمسارات المنحنية والمناطق، والتراجع/الإعادة والحفظ المحلي والاستيراد والتصدير بصيغة JSON.

إذا وُجدت خطة محفوظة بالمعرّف القديم `tactical/plan` ولم توجد خطة للمحرر الجديد، يحاول المحرر نقل مواضع اللاعبين إلى مخططه الجديد مرة واحدة دون تعديل السجل القديم. تفاصيل اللاعب القديمة غير الممثلة في المحرر الجديد تبقى في السجل القديم.

### 3. إدخال الأداء والتحليلات
- أضيفت حقول اختيارية لتحديد الفريق الذي لعب معه المستخدم، أهدافه الشخصية، الصناعات، دقائق المشاركة، وتقييم ذاتي من 1 إلى 5 لعدة محاور.
- تظل الحقول الجديدة اختيارية ومتوافقة مع السجلات الأقدم التي لا تحتوي عليها.
- القيمة الفارغة تعني **غير معروفة/غير مسجلة**، ولا تُحسب تلقائيًا كصفر.
- يمكن فتح نتيجة مباراة مؤرشفة وتعديل بيانات الأداء المرتبطة بها.
- صفحة التحليلات تقرأ من سجل المباريات الحالي، وتوفّر تصفية بالفترة الزمنية وصيغة اللعب، ورسمًا للمساهمات حسب المباراة، وتوزيع النتائج، ومتوسطات التقييم الذاتي، وقائمة بالمباريات التي بُني عليها التحليل، واقتراحات عملية حذرة.
- لا تستنتج الصفحة التمركز أو اللياقة أو جودة الضغط تلقائيًا من النتيجة وحدها.

### 4. الملاعب والمساعد
- تستمر صفحة الملاعب باستخدام دليل الملاعب والبحث الموجودين في 2.0. الخريطة التفاعلية مؤجلة عمدًا لهذه المرحلة.
- صفحة مساعد تأمين تعمل حاليًا بقواعد محلية محدودة، وتستطيع قراءة الإحصاءات المسجلة يدويًا وتقديم إرشادات عامة. لا تتصل بنموذج ذكاء اصطناعي خارجي ولا ترسل المحادثة إلى خادم؛ هذه معاينة أولية وليست تكامل AI إنتاجيًا.

### 5. الإعدادات والملف الشخصي والدعم
- زر الإعدادات يفتح صفحة بثلاثة اختيارات: الإعدادات، الدعم والتواصل، والملف الشخصي.
- صفحة الإعدادات تحتفظ بإعدادات المظهر واللغة والبيانات والخصوصية والتثبيت الموجودة في 2.0.
- الوضع الداكن يبقى الافتراضي عند عدم وجود تفضيل محفوظ. تغيير اللغة موجود داخل الإعدادات.
- صفحة الدعم الأصلية أصبحت وجهة منفصلة يمكن الوصول إليها من صفحة الحساب.
- أضيف أسفل الرئيسية تعريف صغير بالمطوّر يربط إلى صفحة عمر الشخصية فقط، دون روابط مستودعات.

## التشغيل المحلي

يفضل استخدام إصدار Node.js متوافقًا مع Vite 8 (مثل Node 22.16 أو إصدار حديث متوافق).

```bash
npm ci
npm run dev -- --host 127.0.0.1
```

افتح العنوان المحلي الذي يطبعه Vite في الطرفية. لفحص بناء الإنتاج وتشغيل اختبارات المشروع بعد تثبيت التبعيات:

```bash
npm run build
npm test
```

## حالة التحقق في بيئة إعداد الملف

تم فحص البنية النحوية لـ 156 ملف TypeScript/TSX من ملفات المصدر والاختبارات دون العثور على أخطاء تحليل نحوي. كما نجح اختبار وجهات التنقل الثلاثة، وفحص الخصوصية النهائي. تعذّر إكمال `npm ci` والبناء والاختبارات هنا لأن بيئة العمل لم تتمكن من حل اسم `registry.npmjs.org`، ولذلك لم تتوفر التبعيات المطلوبة. يجب تشغيل `npm ci` ثم `npm run build` والاختبارات على جهاز متصل بالإنترنت قبل اعتماد هذه النسخة أو نشرها.

- لم تتم إضافة مصادقة أو مزامنة سحابية جديدة.
- المساعد ليس موصولًا بخدمة ذكاء اصطناعي خارجية.
- لم يتم نشر أي تعديل إلى `taamenn.com`.
