# TAAMEN V16 — ربط الملعب التكتيكي بـ TAAMEN AI

V16 مبنية على V15 Remaster. هدفها أن يقرأ TAAMEN AI حالة الملعب التكتيكي الفعلية من `Tactical Plan Schema v1`، وليس مجرد وصف عام يكتبه المستخدم.

## طريقة الاستخدام

1. افتح الملعب التكتيكي باستخدام ملف TAAMEN محلي.
2. عدّل الملعب 5v5 أو 7v7: اللاعبين والتشكيلة والرسومات والمناطق.
3. اضغط **حلّل الخطة مع TAAMEN AI**.
4. راجع نافذة الموافقة التي تشرح البيانات المرسلة، ثم وافق.
5. ينتقل الموقع إلى TAAMEN AI ويعرض بطاقة بالخطة المرفقة.
6. اكتب سؤالك. تبقى الخطة مرفقة لأسئلة المتابعة حتى تزيلها أو تنتهي صلاحيتها أو تعيد ضبط المحادثة أو توقف AI.

لا تُرسل الخطة بمجرد فتح الملعب أو المساعد. تُرسل فقط مع سؤال بعد تأكيد المستخدم. تنتهي صلاحية المرفق بعد 30 دقيقة.

## ما الذي يقرأه المساعد؟

- صيغة اللعب 5v5 أو 7v7 والتشكيلة.
- أسماء وأرقام ومواقع جميع اللاعبين في الفريقين.
- أنواع الرسومات: `pass`, `run`, `press`, `curve`, `multiCurve`, `zone`.
- ألوان/أنماط الرسم ونقاط البداية والنهاية ونقاط التحكم/المراسي.
- ملخص يوضح عدد الرسومات المرسلة والمسارات المختصرة والرسومات المستبعدة.

لا يستنتج اتجاه الهجوم أو مركز اللاعب من رقم القميص. وقد تختصر المسارات الطويلة إلى 8 نقاط ممثلة، وقد تُستبعد رسومات إضافية للحفاظ على حجم السياق؛ يظهر ذلك للمستخدم في بطاقة المرفق.

## حدود البيانات والخصوصية

- المخطط المصدر هو `TacticalPlanDocument` بعد التحقق من Schema v1.
- تُحفظ وصلة الخطة مؤقتاً في `sessionStorage` للتبويب الحالي فقط، لمدة لا تتجاوز 30 دقيقة.
- حد سياق العميل 8,000 حرف و12 KiB UTF-8.
- الحد الأعلى 18 رسماً و8 نقاط مرسلة لكل مسار.
- لا تُرسل صورة الملعب أو ملف JSON الخام.
- Worker يعيد التحقق من أسماء الحقول والأعداد والإحداثيات وأنواع الرسومات والأنماط واتساق هندسة المسارات قبل حجز حصة AI أو تشغيل النموذج.
- تعليمات النموذج تعتبر أسماء الخطط وملاحظاتها أسماء بيانات وليست تعليمات.
- المساعد يقدم تحليلاً واقتراحات فقط؛ لا يعدّل الخطة تلقائياً.

## ما لم ينفذ في V16

- لا توجد حسابات أو بريد إلكتروني.
- لا يوجد حفظ سحابي للخطط أو D1 أو مزامنة بين الأجهزة.
- لم يتغير نموذج GPT-OSS 120B أو مستوى reasoning `low` أو نظام الحصص.
- لم يتم النشر إلى Cloudflare أو الموقع الحي.

## أوامر Windows PowerShell

```powershell
npm ci
npm run typecheck
node --test --experimental-strip-types src/services/tacticalPlanAIContext.test.ts src/services/tacticalPlanAIIntegration.test.ts
npm run test:frontend
npm run test:backend
npm run test:worker
npm run qa:final
npm run build:production
npm run preview
```

لا تنفذ `wrangler deploy` ضمن اختبار V16. اختبر أولاً إرفاق الخطة، ظهورها في المساعد، ثم وصول إجابة حقيقية من GPT-OSS في Cloudflare Preview.
